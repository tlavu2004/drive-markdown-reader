# Code of Conduct

## Expectations

Treat everyone participating in Drive Markdown Reader with respect. Welcome different backgrounds and experience levels. Give constructive feedback about code and ideas, explain disagreements, and respect others' time and privacy.

Harassment, threats, discriminatory remarks, sexual harassment, deliberate disruption, and publishing another person's private information without permission are not acceptable.

## Scope

These expectations apply to project issues, pull requests, discussions, and other spaces maintained for Drive Markdown Reader, including communication when representing the project.

## Reporting and enforcement

Report concerns privately to **truongleanhvu20052004@gmail.com**. Include relevant context while minimizing personal information. The maintainer will handle reports with discretion, but cannot promise absolute confidentiality or a fixed response time.

The maintainer may edit or remove inappropriate content, request behavior changes, close or restrict a discussion, or temporarily or permanently limit participation. Responses should reflect the severity and repetition of the behavior. Reporters and participants should not face retaliation for raising concerns in good faith.

Maintainer decisions may be discussed privately through the same contact address. This policy applies to maintainers as well as contributors.
