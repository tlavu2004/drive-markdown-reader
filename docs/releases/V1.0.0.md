First packaged release of Drive Markdown Reader for desktop Chrome.

- Render Mermaid diagrams from Markdown files in Google Drive and switch between graph and source.
- Use light or dark reading themes and zoom controls.
- Read Markdown source from Drive's current native preview, including its same-origin iframe.

Download `drive-markdown-reader.zip`, extract it, then open `chrome://extensions`, enable **Developer mode**, and select **Load unpacked**. Choose the extracted folder containing `manifest.json`. The separate `.sha256` file verifies the ZIP download.

Relative images or links may fail, and file navigation depends on the available Drive context. See the [installation guide](https://github.com/tlavu2004/drive-markdown-reader/blob/v1.0.0/docs/guides/INSTALLATION.md).
