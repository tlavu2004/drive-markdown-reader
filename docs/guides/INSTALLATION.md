# Installation and troubleshooting

## Install from a release

1. Open [GitHub Releases](https://github.com/tlavu2004/drive-markdown-reader/releases) and select a published version. If none is available, use [Install from source](#install-from-source).
2. Under **Assets**, download `drive-markdown-reader.zip`. The autogenerated **Source code** archives require a build.
3. Optionally download `drive-markdown-reader.zip.sha256` alongside the ZIP. Compare it to `Get-FileHash ./drive-markdown-reader.zip -Algorithm SHA256` on Windows, or run `sha256sum --check drive-markdown-reader.zip.sha256` where available. Stop if the checksum differs.
4. Extract the ZIP and keep the extracted directory in place. At `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the folder that directly contains `manifest.json`.

To update, replace the extracted files in the same folder, click **Reload** on the extension card, and refresh the Drive tab. GitHub ZIP installations require manual updates.

## Install from source

Use desktop Chrome and Node.js 24.15 or later in the 24.x line. From the repository root, run:

```sh
npm ci
npm run build
npm run verify:extension
```

Load `dist/` from `chrome://extensions` using **Load unpacked**. After rebuilding, reload the extension and refresh Drive.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| Chrome cannot find the manifest or reports a TypeScript MIME error | Select the extracted release folder containing `manifest.json` or the generated `dist/` folder. |
| The reader cannot find Markdown | Close the extension viewer, select Drive's **Markdown** source tab, and click **Render Markdown**. Preview extraction depends on the markup Drive exposes and requires an accessible source block. |
| File download fails | Confirm that the current Drive account can download the file. If Drive shows its Markdown source, try it with the manual render button. |
| A Mermaid diagram appears as code or reports an error | Select **Graph** and use a fenced block labeled `mermaid`. Switch to **Code** to inspect the source. |
| An image or link is missing | Relative paths may resolve against the extension iframe. Use an accessible absolute URL, or open the original document for its links. |
| Previous or Next is unavailable | Navigation needs the current file ID and a neighboring file visible to the extension in Drive's DOM. |
| An update seems unchanged | Check which folder Chrome loaded, reload the extension, and refresh Drive. |

See [Testing and delivery](TESTING.md) for Chrome smoke checks.
